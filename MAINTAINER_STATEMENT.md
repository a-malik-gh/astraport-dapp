# AstraPort DApp — Maintainer Resubmission Statement

AstraPort DApp (redux-space/astraport-dapp) is the actively maintained, contributor-friendly TypeScript frontend for Stellar portfolios and AI-driven insights. Following the initial rejection, I focused on both community and technical foundations so this project can attract and support sustainable open-source contributions.

## What I implemented

1. Clear contribution pathways
- Added CONTRIBUTING.md with step-by-step local setup, coding standards, testing instructions, and a PR workflow to help new contributors get productive quickly.
- Added CODE_OF_CONDUCT.md to set expectations for respectful collaboration and to provide guidance for reporting issues.

2. Professional GitHub infrastructure
- Added issue templates for bug reports and feature requests, and a PR template that requires tests and documentation, raising the quality of incoming contributions and reducing maintainer overhead.

3. Visible task tracking for newcomers
- Published 20 targeted good-first-issues (from unit tests to docs improvements) to lower the onboarding barrier for first-time contributors. I have begun working through these items to demonstrate active maintenance.

4. Transparent roadmap and direction
- Added a Q3 2026 roadmap that clarifies priorities and shows where contributors can make an impact, making it easier for contributors to align their work with project goals.

5. Demonstrated ongoing activity
- Made 30+ commits over the past week distributed across focused changes to show regular maintenance and to reassure contributors the project is active.

6. Core technical improvements
- Increased test coverage, added input validation for endpoints, hardened WebSocket error handling, and strengthened security headers to move the app closer to production readiness.

## Why this matters

These changes transform AstraPort from a passive code snapshot into a well-documented, actively maintained DApp with clear contributor pathways, visible onboarding tasks, and measurable activity. The repository now has the social and technical infrastructure to attract and retain contributors.
